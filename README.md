# Belgische Vastgoed Investeringsengine

Institutionele investeringsengine voor Belgische vastgoedcases met:
- regionaal parametriseerbare fiscaliteit (VL/BRU/WAL)
- financiering + meerjaren cashflow (20+ jaar)
- exitmodel (growth/cap-rate)
- KPI-set (yield, CoC, DSCR, IRR, NPV, total return)
- sensitiviteitsanalyse
- GO/CONDITIONAL/NO-GO engine
- audit trail per berekening

## Run tests

pytest -q
